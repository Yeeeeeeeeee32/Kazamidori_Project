## 2024-06-19 - QSS Focus Outline and Layout Shifts
**Learning:** When applying custom stylesheets (QSS) to widgets like `QPushButton` or `QToolBox::tab` in PySide6/Qt, default OS/Qt focus indicators are often overridden or lost. To maintain keyboard accessibility, always explicitly re-implement `:focus` pseudo-class styles (e.g., `outline: none; border-color: ...`) for clear visual feedback during tab navigation. Additionally, widgets styled with `border: none` will suffer layout shifts when a focus border is applied; ensure they have transparent borders by default (e.g., `border: 1px solid transparent;`) and adjust padding proportionally to prevent this.
**Action:** When customizing UI components with QSS, always include `:focus` pseudo-classes to ensure keyboard navigability, and prefer transparent borders over `border: none` for borderless elements to prevent layout shifts.
