## YYYY-MM-DD - Enforcing genuine empty UI states
**Learning:** In PySide6/PyQt applications, enforcing genuine empty states for numeric inputs using sentinel hacks (like `-9999.0`) on `QDoubleSpinBox` creates poor UX and complex controller logic. It's much more accessible and intuitive to use `QLineEdit` combined with `QDoubleValidator`.
**Action:** Always use `QLineEdit` with a `QDoubleValidator` for numeric fields that allow empty states. Visually signal invalid/empty states by styling their borders red (`border: 1px solid red;`). Map empty inputs to `None` in `AppState` via the `editingFinished` signal (avoid `textChanged` to prevent recursive cursor resets during bi-directional syncing), and wrap the `float()` casting in a `try...except ValueError` block. Use `.setClearButtonEnabled(True)` to provide a standard clear button.
