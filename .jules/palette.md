## 2024-05-28 - Manual Config Apply / Cancel Buttons
**Learning:** The `Manual Config` dialog lacked an explicit way for users to accept or discard their changes, relying solely on a "Close" button. The requirements highlighted this as a UX issue because the user wasn't sure if closing the dialog would apply or cancel their unverified changes. Implementing explicit `Apply` and `Cancel` buttons, and wiring `Cancel` to reject and reset the changes, provides users with clear action paths, conforming to established modal dialog paradigms. This is particularly important for configuration settings where users might want to back out of accidental inputs.
**Action:** Always provide explicit Apply/Ok and Cancel buttons for modal dialogs where the user is editing state. Never rely on implicit "Close" behavior unless changes are saved instantaneously (and safely), and even then, make sure it's clear to the user.
