## 2024-05-16 - Fusing multiple O(N) array passes in Monte Carlo hot paths
**Learning:** In the inner loop of Monte Carlo simulations (`_perturb_wind_profile` and `apply_gust` for `ui_qt/workers.py`), Python's iteration overhead from chaining sequence-processing loops (`zip`, list comprehensions, etc.) adds significant latency. We observed ~18% execution time reduction strictly by fusing three independent O(N) passes (global/local noise application, gust noise application, scalar hypotenuse calculations) into a single unified pass over the layers.
**Action:** When a loop generates inputs for a second mapping function immediately in the same hot path, always examine whether the transformations can be merged to eliminate intermediate list allocations and duplicated loop overhead.
