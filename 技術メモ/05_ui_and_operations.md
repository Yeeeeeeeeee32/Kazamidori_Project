# UI・操作・モード

更新日：2026-10-27。状態：現行仕様と追加候補。

## 画面と実行

PySide6 Widgets・Matplotlibを使用し、左に入力／結果、右上に3D軌道と2D地図、右下に風況を配置します。
QSplitterで領域を調整できます。左パネルはスクロール対応で、長文による領域幅の変更を抑えます。
進捗バーは割合、隣の欄は段階名、下部は詳細状態を表示します。省略された1行表示の全文はツールチップで確認できます。
Run（F5）は自由モードで指定角度の公称計算＋MC、それ以外で発射角探索＋MC検証を行います。
Stop（Esc）は取消要求を送り、実行中の積分等が戻るまで待ちます。進捗は全体で0〜100%として表示します。
完了・失敗・不適合の理由を通知し、計算失敗を成功軌道として描画しません。

## モード

| モード | 評価・制約 |
| --- | --- |
| 定点滞空 | `A × (Maximum Radius − 目標からの距離) + B × 飛行時間`。A/Bは設定可能 |
| 高度 | 最高高度 |
| 有翼 | 放出から着地までの時間。専用の滑空・操舵・分離モデルではない |
| 自由 | 目標円による制限なし。指定した角度で評価 |
| モンブラン | 着地直前の速度・安定性・目標範囲を制約とし、適合候補の区間最大速度＋変動幅を小さくする |

競技モード、探索／監視の運用段階、開発計画、UI移行段階は別の軸です。
得点・要求確率・半径の設定が、特定年度の競技規則への自動適合を保証するものではありません。

## モンブラン条件

| 入力 | 定義 | 仮の初期値 |
| --- | --- | --- |
| 最大水平速度 | 評価区間の対地水平速度の上限 | 3.00 m/s |
| 評価時間 | 地面接触直前から遡る時間 | 3.00秒 |
| 許容速度変動幅 | 同区間の水平速度の最大値−最小値 | 0.50 m/s |

初期値はチームの実測・要求値ではありません。必要な値を入力します。
水平速度は`sqrt(vEast²+vNorth²)`で、対気速度・鉛直速度とは別です。速さ一定の方向変化を速さの変動には数えません。
評価区間全体が開傘完了後であり、区間最大速度と変動幅が双方の上限以下なら速度条件に適合します。
評価時間不足や直前区間での超過を、着地時点だけ速度が低いことによって適合扱いにしません。着地後の速度0も追加しません。
ソルバー出力間の速度ベクトルを線形補間し、窓境界とベクトル回転による区間内部の速さの最小値を含めて評価します。
Maximum Radiusも維持します。MCの全条件適合率は計算失敗を含む全試行を分母にします。
最終GOには公称計算の速度条件適合、完了4件以上、指定確率以上の全条件適合率が必要です。
結果欄には着地速度、区間最大速度、変動幅、評価時間の確保、公称適合、MC適合件数を表示します。
該当する発射角がなければ理由を通知し、モータ・傘・追従率を無断で変更しません。
これは評価・探索であり能動的な速度制御ではありません。振り子運動も未実装です。
GOは計算時の条件に対する結果で、速度条件のライブ再評価には再計算が必要です。

## 表示・地図・予報

- 3Dカメラの回転と発射角入力を区別する。Shift＋ホイールは計算済み軌道の時刻再生。方位軸はグラフ外側に配置する。
- ViewからKDE・CEP・散布・燃焼終了・頂点の表示を切り替える。切替だけで飛行を再実行しない。
- 地図は保存した背景画像・メタデータを用いる。パン／ズーム・Ctrl＋クリックによる発射位置入力を扱う。
- 地図欠損・地点不一致・範囲外・現在地取得失敗を通知し、任意の既定地点を取得成功として扱わない。
- 風の履歴は1.5 m、他高度は平均を表示。模擬風と予報と実測を区別する。
- 事前予報ダウンロードはオンライン、保存済みCSVの利用と地図表示はオフライン。日時の表示はJST。

## 追加候補

屋外配色、NO-GO超過量、パネル配置の保存、入力連動プレビュー、v-t／h-t／側視図、禁止領域、等高線を検討します。
公称プレビューは非同期・デバウンス・最新要求優先とし、本計算のGOを上書きしません。
非表示でも受信・統計を継続し、再表示時に最新化します。古い結果・入力変更・未取得を表示上でも区別します。
描画改善はカメラ・凡例・カラーバーの重複、通常／縮小サイズ、入力変更中と取消中を確認します。
