# 飛行・モータ・回収モデル

更新日：2026-10-27。状態：現行モデル`time-events-v2`とその制約。
主な実装：[simulation.py](../core/simulation.py)、[parachute_drift.py](../core/parachute_drift.py)。

## 開傘と計算終了

燃焼終了＋放出遅延まで積分し、同じ機体モデルへ完全な状態を引き継いで開傘区間を計算します。
開傘はRocketPyの実イベントと開傘ラグを使います。公称計算・探索・MCは同じ時間イベント式の入口を使用します。
地面到達、有限な軌道、最終高度、実際の開傘を確認してから成功とします。
未離床、開傘前の着地、未開傘、着地前の時間打切りは成功点に含めません。
標準の時間上限は120秒。モード別のrtol・atol・最大刻みを各Flightに渡します。

## モータ近似

推力曲線の台形積分による全力積をJとし、仮定した比推力Ispから`m_prop = J / (Isp × g0)`を推定します。
既定のIsp＝80秒、推進剤密度＝1700 kg/m³は仮定値です。
機体半径Rに対し、仮のグレイン外半径は`0.80R`、内半径は外半径の`0.40`倍。
環状断面積Aは外半径円の84%、体積Vは`m_prop / density`です。
`n = max(1, ceil(V / (A × 2r_out)))`、各高さは`V / (nA)`とします。
ノズル半径は内半径の0.70倍、スロート半径はノズル半径の0.50倍。
グレイン間隔は0、中心位置はモータ座標原点、乾燥慣性は固定近似値です。

推力曲線や型番だけから実物の内部形状・CG・慣性を一意に復元しません。
ケース外径、長さ、マウントの実寸適合と、初期静安定の検査は別の確認です。
RASP/ENG形式から内部グレインや燃焼則を直接取得できるとは扱いません。
Knを扱う場合の定義は燃焼面積／スロート断面積で、燃焼圧を求めるには追加の仮定が必要です。

## 機体・空力・大気

- 質量・CG・形状の取得元は.ork→自動計算→手入力の順。部品モデル由来の質量・CGは実測値と区別する。
- 慣性未指定時は一様円柱近似。部品別慣性計算関数の存在だけで全GUI入力が結合済みとは扱わない。
- CP指定はMach 0を基準とした補正。全Mach域の実測空力ではない。
- Cdは推進中／燃焼終了後の定数またはMach曲線。Cdと基準面積を組で扱う。
- 初期静安定の検査は、燃焼過程・全速度域・レール離脱速度の運用基準を網羅しない。
- AGLを原点としEnvironmentのelevationは0。現地気圧・気温と一定気温減率による大気近似で、湿度は密度に未反映。
- 圧力は0〜20000 mの単調テーブルを用い、環境生成時に圧力↔高度の往復を確認する。
- 風成分は高度に対して線形補間し、範囲外は端値を保持する。実地形・地表境界層を完全に再現するモデルではない。

## パラシュート

RocketPyへCdSを渡し、開傘後の降下を計算します。
水平追従率を指定した場合は、開傘後の水平速度を「局所風ベクトル×追従率」として水平位置を積分し直します。鉛直軌道は変更しません。
追従率を指定しないAPI経路では、元のRocketPyの水平運動を保持します。
振り子運動、索の張力、傘と機体の結合運動、能動制御は含みません。

抗力は`D = ρ V_rel² Cd S / 2`。相対風速・布面積・投影面積の定義を混同しません。
理想的な鉛直定常降下の`Vt = sqrt(2mg / (ρ Cd S))`は、開傘過渡・揺れ・実降下を保証する式ではありません。
形状名だけでCdを確定せず、面積定義・出典・測定条件を持つCdSを使います。

## 継続して検証すること

実開傘イベント、傘面積への降下時間の応答、未着地の失敗扱い、圧力高度往復、入力の無断補正がないことを確認します。
時間刻み・許容誤差の収束、無風時の対称性、質量収支・重心・慣性の原点移動不変性も確認対象です。
代表試験：[飛行回帰](../tests/core/test_regression.py)、[物理・入力検証](../tests/core/test_audit_fixes.py)、[数理検証](../tests/core/test_math_physics_audit.py)。
これらはモデル内の整合性であり、実測による空力・モータ・傘の同定とは別です。
