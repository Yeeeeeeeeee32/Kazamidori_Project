# 気象・統計・判定

更新日：2026-10-27。状態：現行実装と入力基盤の設計要件。

## 気象データ

Koinoboriの基準高度は1.5 m AGLです。現在は練習用の模擬風・気圧・温湿度を使用し、実機通信は未接続です。
練習風の平均風速・風向は編集でき、ランダム性を保持します。タイマー生成の再現用シード・シナリオ再生は未実装です。
Open-Meteoから対象期間の風をCSVへ事前取得できます。CSVの対象地点・UTC時刻を選択し、現地気圧Pa・気温を使って等圧面をAGLへ換算します。QNHと現地気圧は別物です。
予報を選択した上空層は練習タイマーで上書きしません。地点・CSV・対象時刻の変更時には上空履歴・平均をリセットします。

地表風の履歴は最大60サンプル。60秒を保証する時間窓ではありません。
保持中の風速から`μ = Σs/N`、`σ = sqrt(Σ(s−μ)²/N)`を求め、μが0.1 m/sより大きい場合にTI＝σ/μを計算します。
正のauto_gust_ms（観測風速のσ）は手動ガストより優先します。
表示は1.5 mに履歴と観測点、他の高度は平均のみ。表示用平均と計算プロファイルは区別します。

## 方向と摂動

北0度・時計回りのFROM風向θと風速sから、東・北への風成分は`u = −s sinθ`、`v = −s cosθ`です。
359度と1度を算術平均せず、u/vや円統計を使います。平均風速と平均ベクトルの大きさは異なり、無風付近の方向統計は慎重に解釈します。
MCは各試行に静的な高度別摂動と推力スケールを与えます。探索と通常MCは共通の風摂動モデルを使用します。
試行シードは試行IDに対応付けます。飛行中に時間発展する乱流モデルではありません。

## 着地分布の指標

| 指標 | 意味 |
| --- | --- |
| CEP50 | 成功した着地点群の平均を中心とする距離の中央値 |
| 表示用Rパーセンタイル | 同中心からの距離の分位点。線形補間の分位点を使用 |
| 共分散楕円 | 標本平均・標本共分散に基づく2次元正規分布近似の確率領域 |
| KDE等高線 | 等間隔格子の密度を積算した確率質量に対応する高密度領域 |
| GOの円内率 | 目標中心・Maximum Radiusの円内に入った試行数／全試行数 |

楕円の半軸倍率は`sqrt(−2 ln(1−p))`で、90%なら約2.146。
最大固有値の固有ベクトルに対する`atan2(North, East)`を東基準反時計回りの角度として描画・保存します。
楕円は平均値の信頼領域ではなく、非正規・多峰性分布でKDEと一致する保証もありません。
同一点・一直線等でKDEを生成できなければ、KDEなしで散布点を表示します。

## GOと探索の契約

自由モードは着地半径でGO／NO-GOを評価しません。それ以外の通常判定は、成功点4件以上と指定確率以上の目標円内率を要求します。
計算失敗は円外として分母に含めます。成功点だけの得点平均・最低値と、完了／失格／失敗件数を区別します。
探索制約の半径は目標中心からの全試行の最近順位分位点で、失敗は無限大として扱います。表示用の中心・分位点とは用途が異なります。
モンブランは速度・安定性・着地範囲の同時適合率を使います。詳細は[UI・モード](05_ui_and_operations.md)を参照。
GOは経験割合であり、真の確率の統計的な信頼下限を計算する実装ではありません。

Phase Bは計算時の地表風ベクトルからの差を使う簡易監視です。動的MC・CEP更新や上空風の常時再取得ではありません。
監視係数を2次元の95%保証と解釈しません。モンブランでは速度窓を再評価できないため、Phase BによるGO自動更新を開始しません。

## 次の設計要件

受信・表示・統計の周期を分離し、時間幅と容量上限を併用する長期バッファを設けます。
欠測・重複・遅延・不等間隔・時計ずれ・測器校正と、地表風／環境値／予報それぞれの鮮度を管理します。
σを増やすだけで古い入力を保守的とみなさず、期限切れと判定不可を明示します。
自己相関を持つ観測を独立標本とみなしません。スペクトル解析には周期・前処理・観測時間が必要です。
一高度だけから上空の突風、粗度z0、摩擦速度等を一意に推定しません。
